## 1. 总科学问题

本文希望解决的问题不是工作记忆能否存储信息，而是：

> **在同一个固定回路中，工作记忆表征如何随着连续输入逐步演化？**

“状态能够跨越输入间隔被继承”只是这一问题成立的必要前提，不是论文的中心结论。

## 2. 核心机制答案

本文希望建立的机制答案是：

> **当前层继承的分布式 STSP 状态调制新输入在该层的处理；这一历史条件化处理进一步在下一层形成新的继承 STSP 状态。该 successor state 同时整合既有历史与当前输入，并参与后续输入的处理。**

因此，工作记忆演化的基本单元是一次层间状态转移：

```text
当前层继承的工作记忆状态
          +
       当前新输入
          ↓
历史条件化的当前层处理
          ↓
下一层形成 successor state
```

## 3. 方向性必须保持准确

正确关系是：

```text
第 l 层的继承状态
→ 调制新输入在第 l 层的处理
→ 改变传向第 l+1 层的活动与更新
→ 在第 l+1 层形成新的继承状态
```

不应写成：

```text
第 l 层的继承状态
→ 本层处理
→ 改写同一层的继承状态
```

因此，本文讨论的不是同层状态的自我写回，而是**历史条件化处理所驱动的层间 successor-state formation**。

## 4. 历史与新输入的职责

本文不主张正确答案由历史决定。

- **当前新输入**是当前判断和状态变化的主要驱动力；
- **继承历史状态**提供处理上下文，调制网络如何响应当前输入；
- **下一层 successor state**是既有历史与当前输入经过当前层处理后形成的新工作记忆表征。

因此，历史不是替代当前输入，而是改变当前输入在同一回路中被变换和向下游传递的方式。

## 5. Successor state 的含义

下一层形成的 successor state：

1. 不是旧历史状态的简单复制；
2. 不是当前新输入的普通前馈重编码；
3. 是既有历史与当前输入经过当前层处理后形成的重新组织状态；
4. 仍可对之后的输入产生历史依赖影响；
5. 因而可以成为下一次状态转移的继承条件。

Successor state 是否同时保留历史依赖和当前输入贡献，是区分“工作记忆表征演化”与“普通前馈传播”的关键。

## 6. 连续演化主张

本文希望主张：

> **“继承状态参与当前处理并形成下一层 successor state”这一转移原则，会在连续输入到来时反复发生，因而构成工作记忆逐步演化的基本单元。**

因此，完整过程是：

```text
继承状态₀
→ 输入₁驱动、历史调制的层间转移
→ successor state₁
→ 输入₂驱动、历史调制的层间转移
→ successor state₂
→ ……
→ 结构化的工作记忆状态轨迹
```

这里的“演化”不能仅指状态数值不断变化。它必须意味着：

- 每一步主要由新输入驱动；
- 每一步仍受到既有历史状态调制；
- 每一步在下一层形成新的可继承状态；
- 连续转移产生的状态不是被动衰减、随机漂移或输入简单累计；
- 最终状态仍保留结构化的历史依赖，并能够影响后续处理。

## 7. 整篇论文的论证骨架

### 第一层：必要前提

证明上一阶段形成的状态能够在没有持续放电的情况下被下一阶段继承。

这一层只回答“状态转移从哪里开始”，不承担论文主要创新。

### 第二层：证明一次基本状态转移

需要证明：

1. 在当前新输入完全相同时，不同继承状态导致不同的当前层处理；
2. 这种差异不是输入差异造成的；
3. 操纵当前层继承 STSP 能够定向改变下一层的更新；
4. 下一层 successor state 同时包含当前输入贡献和可识别的历史依赖贡献。

这是全文最核心的机制证据。

### 第三层：证明基本转移会反复发生

需要证明：

1. 该转移不是单个输入或单个阶段的偶发现象；
2. 连续输入到来时，successor state 会继续成为后续转移的继承条件；
3. 状态由此逐步偏离仅由 passive evolution 产生的轨迹；
4. 重复转移仍保持相同的方向性原则：新输入驱动、历史状态调制、下一层形成新状态。

### 第四层：证明反复转移产生有意义的工作记忆组织

需要证明：

1. 多次转移后的状态仍然包含结构化内容，而不是无意义漂移；
2. 既往项目以经过重组的形式保留在最终状态中；
3. 最终状态能够在适当输入或 cue 下影响后续处理；
4. 项目数、延迟和输入条件共同限定这种状态演化与访问的 operating regime。

## 8. 论文的中心结论

推荐的中文中心结论：

> **在固定的脉冲神经回路中，工作记忆表征通过反复发生的层间状态转移逐步演化：当前层继承的 STSP 状态调制新输入的处理，而该处理在下一层形成同时整合历史与当前输入的 successor state。**

推荐的英文中心结论：

> **Working-memory representations evolve through repeated inter-layer state transitions in a fixed spiking circuit: inherited STSP at the current layer conditions the processing of a new input, and that processing forms a downstream successor state integrating prior history with the new input.**

更凝练的机制表述：

> **Input-driven, history-conditioned inter-layer state transition is the basic unit of working-memory evolution in this model.**

## 9. 明确不属于本文中心主张的内容

本文不以以下命题为主线：

- STSP 能够存储信息；
- 历史决定当前输入的正确答案；
- 动态 STSP 必然提高当前分类准确率；
- 新输入在同一层反向改写同一继承状态；
- 任意状态变化都可以称为工作记忆演化；
- STSP 是唯一可能的工作记忆机制；
- 模型内层间转移已经等同于生物大脑中的普遍机制。

这些内容中，“STSP 可被继承”和“演化后的状态可被访问”分别只是机制前提和结果验证，不能替代层间状态转移这一中心。

## 10. 后续所有图文的判断标准

任何实验、面板或正文段落都应回答下列问题之一：

1. 它是否建立了层间状态转移的必要前提？
2. 它是否证明了继承状态如何调制当前输入处理？
3. 它是否证明了处理结果如何形成下一层 successor state？
4. 它是否证明该转移原则在连续输入中反复发生？
5. 它是否证明反复转移产生了结构化、可继续使用的工作记忆状态？

如果一个结果不能服务于以上任何问题，它不应占据主图或 Results 主线。
