# 循环 STSP DMS：三张独立连接图复现

状态：**THREE-GRAPH CAUSAL-ROLE REPLICATION（Fig.4 机制未测试；非确认性统计）**

## 结论先行

在 3 张独立生成的 10,000 神经元、20M 连接循环图上，短延迟 delayed-match-to-sample（DMS）行为、silent-state 表征以及查询前 STSP 对最终判断的因果作用得到复现。3/3 网络同时通过四个预设门槛：

1. 完整网络活动能够判断 match/non-match，而只包含 probe 身份的对照不能判断；
2. 延迟末端放电活动不能稳定解码 sample，但查询前 STSP 状态能够稳定解码 sample；
3. 将查询前 STSP 重置为基线会破坏行为读出；
4. 将查询前 STSP 替换为相反 sample 的供体状态，会把输出推向供体标签。

因此，当前结果已不再只是单张连接图上的偶然现象；它支持“sample 信息可保存在 STSP 中，且查询前 STSP 会因果影响 probe 后的最终判断”在不同随机连接实例中的稳定性。

这并没有确认 Fig.4 的完整机制。当前实验没有在连续边界上直接证明 `STSP(t)` 改变紧邻的 `firing(t+1)`，也没有证明该段 firing 继续形成 `STSP(t+1)` 并驱动再下一段放电。它验证的是这条机制链的行为因果前提，而不是机制链本身。

## 冻结设计

- 图种子：`143202461`、`143202462`、`143202463`；每张图均为 10,000 个神经元、20,000,000 条连接，其中 12.8M 条连接带 STSP，7.2M 条为静态连接。
- 三张图具有相同的图生成配置，聚合器已读取持久化图文件并验证：图种子互异，除 seed 外图配置一致。
- 为控制任务采样噪声，三张图共用同一实验配置、试次清单和输入随机种子 `921734`；因此网络间差异主要来自连接图。
- task population 为 0、1、2；sample/probe 各持续 75 ms，sample 从 50 ms 开始，delay 为 125 ms，无 distractor。
- 每个网络各有 12 个训练、12 个验证、12 个测试试次；match/non-match 平衡。行为读出器只在训练/验证分区选择正则化并拟合，然后在测试分区评估。
- 每个测试试次从同一查询前检查点展开自然动力学、STSP reset 和相反 sample 供体 STSP swap 分支。替换只作用于 STSP 状态，不修改膜电位、静态权重或连接结构。

## 已建立的证据层级

结果构成一个跨三张连接图一致的行为—表征—单步因果链：

1. **行为成立且不能由 probe 捷径解释。** 完整响应读出平均达到 0.972，而 probe-only 对照在三张图上均为 0.5。
2. **延迟期信息主要存在于 STSP，而不是持续放电模式。** 延迟放电的 sample 解码平均仅 0.306，查询前 STSP 解码则在三张图上均为 1.0；与此同时平均群体放电率只有约 0.565 Hz。
3. **STSP 状态不仅相关，而且对行为必要。** 查询前重置 STSP 后，行为从平均 0.972 降至 0.528。
4. **STSP 状态包含能够定向改变判断的内容。** 换入相反 sample 的供体 STSP 后，供体标签准确率在三张图上均为 0.917，且供体定向决策分数变化均为正。

reset 可能造成一般性状态破坏，但 swap 的定向效应补足了这一歧义：结果不仅显示“拿掉 STSP 会变差”，还显示“换入哪一个 STSP 状态，判断就朝哪一个供体标签移动”。

这个定向效应的端点仍是整个 probe response window 的冻结行为分数。它不能替代 Fig.4 所要求的局部转移检验：上一层 STSP 是否先改变下一时间段放电，以及这段放电是否再写入下一层 STSP。

## 解释边界与下一步

当前结果支持三图可行性复现，但不应写成最终的跨网络统计证明，原因包括：

- 网络样本量只有 3；
- 每图测试集只有 12 个试次，balanced accuracy 的分辨率有限；
- 只测试 125 ms delay 和无 distractor 条件；
- 每张网络分别拟合读出器，尚未验证跨网络共享读出；
- 没有逐时间窗执行 `STSP(t) → firing(t+1) → STSP(t+1)` 的隔离干预；
- 尚未测试第二次 probe 或规则复用，因此还不能证明下一层 STSP 能够被再次调用。

下一阶段的第一优先级不是增加更多连接图，而是在现有三图协议上增加连续时间边界：只干预 `STSP(t)`，记录紧邻的 `firing(t+1)`，再检验其形成的 `STSP(t+1)` 是否能够驱动 `firing(t+2)`。之后再加入第二次 probe、多 delay 与 distractor；设计稳定后才扩展到至少 20 张独立连接图。
